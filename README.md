# 🔮 ServerScanner Pro — Touhou Alice Edition ✨

Быстрый, многопоточный сканер портов и серверов с визуальным интерактивным интерфейсом в стиле **Touhou Project (Alice Margatroid)**.

---

## 🚀 Быстрый старт

Самый простой способ начать работу — запустить **`start.bat`**. Откроется удобное меню:

```text
================================================================
       🔮✨ TOUHOU SERVER SCANNER PRO - ALICE EDITION ✨🔮
================================================================
  [1] ⚡ Запуск Windows GUI Сканера (ServerScanner.exe)
  [2] 🌐 Открыть Веб-дашборд (index.html)
  [3] 💎 Запустить Ruby Сканер в консоли (src\Ruby.rb)
  [4] 📁 Открыть папку с данными и результатами (data)
  [5] 🖼️  Открыть папку с ассетами (assets)
  [6] 🛠️  Пересобрать ServerScanner.exe (src\Program.cs)
  [0] ❌ Выход
```

---

## 🎮 Доступные интерфейсы

### 1. ⚡ Десктопное приложение (`ServerScanner.exe`)
* Полноценная программа для Windows с анимацией персонажа, звуковыми эффектами и быстрой многопоточной проверкой.
* **Одиночный IP**: введите IP или подсеть `192.168.1.0/24` и нажмите **«⚡ Сканировать этот IP»**.
* **Массовое сканирование**: нажмите **«📂 Выбрать файл с IP...»** (или используйте автозагрузку из `data/targets.txt`) и нажмите **«🚀 Запустить весь файл»**.
* **Экспорт**: кнопки **JSON**, **CSV** и **Excel** для быстрого сохранения отчёта.

---

### 2. 🌐 Веб-дашборд (`index.html`)
* Открывается в любом современном браузере.
* Стильный темный интерфейс с Glassmorphism, анимированными частицами и живой сменой состояний Алисы (статичный кадр в ожидании ➔ танец при сканировании).
* Поддерживает одиночный ввод, загрузку файлов, живой поиск/фильтрацию по таблице и выгрузку в **Excel / CSV / JSON**.

---

### 3. 💎 Консольный сканер (`src/Ruby.rb`)
Консольная утилита с красивым цветным прогресс-баром и гибкими ключами:

```bash
# Базовый запуск (автоматически берёт цели из data/targets.txt):
ruby src/Ruby.rb

# Сканирование одного IP с веб-портами:
ruby src/Ruby.rb -i 1.1.1.1 -p web

# Сканирование подсети с экспортом в Excel:
ruby src/Ruby.rb -i 192.168.1.0/24 -e -p 80,443,8080 -o data/report.xls

# Сканирование в 100 потоков с таймаутом 0.5 сек:
ruby src/Ruby.rb -t 100 -T 0.5
```

## 🔌 Пресеты портов

В программе доступны готовые быстрые пресеты:
* **Web**: `80, 443, 8080, 8443`
* **Top10**: `21, 22, 25, 80, 110, 443, 3306, 3389, 5432, 8080`
* **Common**: популярные порты баз данных, SSH, RDP и веб-сервисов.
* **Диапазоны**: поддерживается формат `1-1024` или перечисление через запятую `80,443,3000-3005`.

## 📂 Структура папок

* **`assets/`** — Анимированные и статичные GIF-аватары (`touhou.gif`, `touhou_static.gif`).
* **`data/`** — Списки IP-адресов (`targets.txt`) и сохранённые отчёты (`.json`, `.csv`, `.xls`).
* **`src/`** — Исходный код C# (`Program.cs`) и Ruby (`Ruby.rb`).
* **`start.bat`** — Интерактивный запуск всех модулей.
